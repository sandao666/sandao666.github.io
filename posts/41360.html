nmap发现开放三个端口：22,80,8080，此外没有其他更多信息

8080端口web下的是 Apache Tomcat 9 的默认欢迎页面，进入http://192.168.43.55:8080/manager/html

发现没有开启后台只拿到一个版本号Apache Tomcat/9.0.107 (Debian) 尝试用Nday攻击都失败了，并没有发现更多有价值的东西

在对http://192.168.43.55进行目录扫描时，上发现/cgi-bin/

什么是 CGI？CGI 是一个早期的 Web 服务器与外部程序交互的标准协议。简单说：让 Web 服务器能够执行服务器上的程序，并把结果返回给浏览器。/cgi-bin/ 是 CGI 程序的默认存放目录，通常在 Web 根目录下，如 /var/www/cgi-bin/ 或 /usr/lib/cgi-bin/。

发现了/cgi-bin/后就有思路了，去扫目录下的.cgi文件，

.cgi 文件是一个可执行的脚本或程序，放在 Web 服务器的 /cgi-bin/ 目录下，用于动态生成网页内容。
